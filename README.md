## 🚧 What I'm Building

### Active Directory Pentest Learning Platform

A personal project in development designed to make Active Directory security practice more structured and accessible. It brings together:

- Guided lessons and study material.
- Quizzes, notes, and learning progress tracking.
- Simulated command-line labs and practical objectives.
- A modular Python/Flask application backed by SQLite.

The project also gives me an opportunity to revisit software engineering concepts while building tools around my cybersecurity studies.
