## 🚧 O Que Estou Construindo

### Plataforma de Aprendizado de Pentest em Active Directory

Um projeto pessoal criado para tornar a prática de segurança em Active Directory mais estruturada e acessível:

- Aulas guiadas e material de estudo.
- Quizzes, anotações e acompanhamento do progresso.
- Laboratórios simulados de linha de comando e objetivos práticos.
- Aplicação modular em Python/Flask com SQLite.

O projeto também me permite aplicar boas práticas de engenharia de software enquanto crio ferramentas em torno dos meus estudos de segurança.
